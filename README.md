# كبابجي أبو محمد – بسيون | المنيو الإلكتروني

منيو إلكتروني تفاعلي لمطعم كبابجي أبو محمد (بسيون، الغربية – شارع 23 يوليو، بجوار قاعة كليوباترا وتاون تيم)، بنفس تصميم منيو مشويات الباشا ومدى.

- **الديمو:** https://moazelshazly23.github.io/kababgi-menu/
- الأقسام: المشويات، الوجبات، الصواني، المطبخ، الفراخ، الفتة، الطاسات، المقبلات، الشوربة، السلطات، الأطباق الجانبية.
- سلة طلبات كاملة: أضف الأصناف، راجع الطلب، وأرسله على واتساب المطعم 01201111005 برسالة مرتبة بالأصناف والإجمالي.
- بيانات المنيو (الأصناف والأسعار) كلها في `menu-data.js` فقط للتعديل السريع.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الصفحة والفوتر وبيانات التواصل |
| `style.css` | التصميم (ثيم الجمر) |
| `script.js` | عرض المنيو + السلة + إرسال واتساب |
| `menu-data.js` | الأصناف والأسعار |
| `logo.png` / `logo.webp` | لوجو المطعم |

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو استضافته على GitHub Pages.
